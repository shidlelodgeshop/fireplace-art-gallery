# Parks & More instrumental queue

EPCOT entrance (2021), Magic Kingdom entrance (2020), then classic EPCOT Innoventions. These full source loops play sequentially and repeat. Screen changes do not interrupt the music. The app saves track ID, playback position and mute preference; reopening resumes the same recording.

YouTube source metadata and each MP3 SHA-256 are in playlist.json. All three files were decoded in full after conversion and matched to a -20 LUFS background listening target with a -2 dBTP ceiling. Original recordings retain their ownership.
