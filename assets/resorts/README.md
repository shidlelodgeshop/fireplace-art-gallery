# Resort TV media

21 unique matching resort welcome screens, 40 lighting variants. Selection excludes old blue information layouts and duplicate area/building uploads. Day and night switch automatically using actual sunrise/sunset at the selected resort coordinates (resort-locations.json). Grand Floridian and Port Orleans Riverside remain daytime until matching original nighttime footage is available. Saratoga Night is a user-approved clean recreation from the daytime artwork and supplied lighting reference.

Saratoga uses sharp still art with native feathered fountain/water motion. Other resorts use original-cadence 30 fps silent scenery loops at normal speed. Native overlays provide Paluch Family, working controls, original-style icons, date/time and weather. The shared weather cache refreshes every five minutes; Parks & More uses the identical selected-resort observation. Music is stored once per resort and continues through an automatic lighting change.

Install the native APK, then use scripts/install-resort-media.py to preload the matching media. This repository contains personal TV assets; original media retain their ownership.
