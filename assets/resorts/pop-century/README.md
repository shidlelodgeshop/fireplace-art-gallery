# Pop Century Resort — 1970s assets

Source: [Pop Century Resort 70s Building Splash Screen](https://www.youtube.com/watch?v=5JHuvmIA1Qg), Silent Steve’s Park Views. Media retain their respective ownership.

- `background-source.png`: exact 1920×1080 frame captured from the user-selected video. It still contains the recorded family, room, weather, date/time and navigation artwork. Personalization by the built-in image editor was rejected; this file has not been altered or installed on the TV.
- `music.mp3`: full 1:56:44 soundtrack. The original 192 kbps MP3 was converted/downloaded through yt-to-mp3.net in the browser at the user's request and is retained locally in Downloads. This repository copy is re-encoded to 112 kbps stereo so it fits GitHub's 100 MiB file limit. No hum removal or other audio filtering was applied.
- `resort.json`: source and intended overlay details for subsequent resort-picker integration.

These are prepared source assets. The current Fire Stick still opens Saratoga; no resort-picker or TV update is included in this asset-only change.
